# er_2001_2011: NLRB Election Reports, Jan 2001 - Mar 2011 (born-digital, nlrb.gov)

Source: nlrbweb/pdf/{cy-2001..cy-2008,fy-2009,fy-2010,fy-2011}__*.pdf. Parsed from `pdftotext -layout`
by er_work/nlrbweb/code/parse.py (-> raw.json) and build.py (-> CSV). Period taken from each table's own
"(CASES CLOSED ...)" header, not the filename.

## Rows
- 123 `monthly` rows, Jan 2001 - Mar 2011, every month exactly once. No missing months.
- 21 `six_month_summary` rows (Oct-Mar and Apr-Sep, printed in each March and September issue with
  Tables 1, 3 and 7), Oct 2000-Mar 2001 through Oct 2010-Mar 2011. new_* come from Table 7 only on these rows
  (new_source=table7). Monthly issues have no Table 7, so new_* is blank on monthly rows.
- No fiscal-year summary is printed in any in-scope file, so there are no fiscal_year_summary rows.
- DOUBLE-COUNT WARNING: per the request, the CSV has one monthly row for every month AND the
  six-month summary rows. Summary rows cover the same months. Use one basis or the other, not both.
  The Oct 2000-Dec 2000 months appear only in the Oct 2000-Mar 2001 summary.

## Checks (all rows, all three tables): all pass
The 1/2/3-union subtotals sum to TOTAL in all 10 numeric columns. won + no-rep = n. Eligible-won +
eligible-no-rep = eligible. AFL-CIO + Unaff = won, for both elections and eligible. Detail-row
election counts sum to TOTAL. Table 7 = Table 1 - Table 3 for every n/won/elig/elig_won
column, both total and 1-union. Zero failures.
Image spot-checks against the rendered pages matched the text layer exactly: Table 3 for 2001-06,
2002-02, 2003-08, 2004-11, 2005-05, 2006-07, 2007-12, 2008-04, 2009-09, 2010-01 and 2011-02; Table 1 for 2001-06
and 2011-02; Table 3 for the Apr-Sep 2005 summary.

## Summary vs. sum of months (important)
For Apr 2001-Sep 2004, the six-month summaries equal (or are within a few units of) the sum of
the monthly tables. Those issues were all released late, from 2003 to 2005, apparently from one data pull.
From Oct 2004 on, the summaries differ from the monthly sums. Summary all_n is usually 1-2% higher.
inc_n is often noticeably LOWER in the summary: Apr-Sep 2005 has 108 in the summary against 139 summed
monthly, and Apr-Sep 2006 has 77 against 88. The figures were checked on the page image. Presumably the
summaries were re-run later with revised data or a revised incumbent flag. Treat the two bases as
different vintages. The spec's preference is the summary rows.

## Duplicates / oddities
- cy-2005__eroct20050.pdf and cy-2005__ernov20050.pdf are text-identical to eroct2005/ernov2005. Only the
  first copy is used. No corrected reissues were found (no "corrected"/"revised" text).
- Oct, Nov and Dec 2009 appear in both the fy-2009 and fy-2010 folders (files eroct2009/ernov2009/erdec2009).
  The copies are text-identical. The fy-2009 folder is misfiled: it holds Oct-Dec 2009, not Oct-Dec 2008. Oct-Dec 2008
  come from cy-2008.
- Some issue numbers printed in the source are wrong or odd: cy-2006__eroct2006 and cy-2007__eroct2007 print
  (ER-200611), the same as November. fy-2010__ermay2010 prints (ER-062010), and the Oct issues print ER-1020xx.
  2001-2004 issues use ER-470..478 or have no number (blank issue field).
- Release dates: the Jan-Sep 2001 issues were released 10 Mar 2003. Other 2001-2004 issues were released between
  Jun 2003 and Jan 2005. Issues from 2005 on were released about one month after the period.
- Starting in 2002, some issues spell it "COLLECTIVE BARGAINING" without the hyphen. The table layout is otherwise unchanged
  throughout. 3-or-more-union rows appear intermittently.

## Skipped files (no SUMMARY TABLE 3 / incumbent table)
fy-2011__april2011, may2011, june2011, july2011, august2011, september2011, fy-2011-election-report:
new case-listing format ("NLRB Elections - Details", run 2012) with no summary tables. The *2023-r-case-rule-fact-sheet.pdf
in each folder is not an Election Report. Files for FY2012 onward were not examined (out of scope).
